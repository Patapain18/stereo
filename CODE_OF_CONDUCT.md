# Code de conduite

## Principe

On est entre amis, on essaye de faire un truc cool ensemble. Sois respectueux, sois sympa, et tout ira bien.

## Comportements attendus

- Être respectueux et bienveillant dans les discussions (issues, PRs, commits)
- Accepter les critiques constructives, en donner avec bienveillance
- Se concentrer sur ce qui est bénéfique pour le projet
- Faire preuve d'empathie envers les autres membres du projet

## Comportements inacceptables

- Insultes, attaques personnelles, harcèlement
- Trolling, commentaires intentionnellement provocateurs
- Discrimination de toute forme (genre, orientation, ethnicité, religion, handicap, âge…)
- Publier des infos privées d'autrui sans permission
- Tout autre comportement qui serait inapproprié dans un cadre pro

## Application

Si tu as un souci avec un comportement, contacte le mainteneur (`@Patapain18`) via GitHub. Les rapports sont traités confidentiellement.

Le mainteneur peut, sans préavis :
- Supprimer / éditer / refuser des commits, issues, PRs ne respectant pas ce code
- Bannir temporairement ou définitivement un contributeur
